The `azure-gigs/` folder contains **Azure Gigs**, a virtual Azure cloud learning simulator (Next.js + PostgreSQL). See [azure-gigs/README.md](azure-gigs/README.md).

The `speakup-ai/` folder contains **SpeakUp AI**, a free-first AI English coach, IELTS practice platform and interview simulator (Next.js + optional Supabase). See [speakup-ai/README.md](speakup-ai/README.md).
